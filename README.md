# Church Growth Intelligence — Interactive Prototype

A static front-end demonstration of a church attendance and outreach analytics SaaS.

## Demo

- Dashboard / attendance trends
- Outreach effectiveness and campaign comparisons
- People journey and follow-up tasks
- Reports, demo CSV export, and settings
- Church workspace switcher with fictional sample data

**All church and personal data shown in this site is fictional.** This prototype is for design and usability review only. It is not a secure multi-tenant SaaS, and its demo actions do not save data permanently. Do not enter real personal, religious, financial, or other sensitive records.

## GitHub Pages publishing

1. Publish this repository as a public repository (if using GitHub Free).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose the **main** branch and **/(root)** folder, then **Save**.
5. After GitHub finishes deployment, open `https://<your-username>.github.io/<repository-name>/`.
